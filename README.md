`Python` `FastAPI` `SQLite` `Jinja2`

---

## ✨ 功能特性

- 暗色主题
- 管理后台
- RESTful API
- 访问统计
- 主题定制

## 🚀 快速开始

```bash
# 克隆项目
git clone https://github.com/dirjaker/portfolio.git
cd portfolio

# 创建虚拟环境
conda create -n portfolio python=3.12 -y
conda activate portfolio

# 安装依赖
pip install -r requirements.txt

# 运行项目
python main.py
```
