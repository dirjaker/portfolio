## [1.0.0] - 2026-06-22

### 🔒 安全修复
- 硬编码密钥改为环境变量读取
- 添加路径穿越防护
- 管理员密码使用 pbkdf2_sha256 哈希存储

### ✨ 新增功能
- **多主题系统**：内置 6 款预设主题（暖日、深夜、晨雾、落日、森林、极光），支持自定义主题创建
- **项目详情页**：卡片点击可跳转到独立详情页，展示完整项目信息
- **管理后台仪表盘**：
  - 四项核心指标（总项目数、可见项目、今日访问、总访问量）
  - 近 7 天访问折线图
  - 项目分类饼图
  - 本月 vs 上月访问对比
  - 热门项目 Top 5 排行
  - 最近访问记录（支持弹窗筛选分页）
  - 服务器实时状态（CPU / 内存 / 磁盘）
- **项目管理优化**：
  - 项目拖拽排序
  - 可见/隐藏项目分区管理
  - 卡片/列表视图切换
- **头像管理**：头像上传、裁剪定位、历史头像记录（最近 3 张）
- **访问统计**：项目访问量记录与统计分析
- **RESTful API**：标准化 API 端点（项目列表、详情、访问记录、个人资料、主题）
- **GitHub Pages 部署**：自动化静态站点生成与部署
- **macOS 应用打包**：支持通过 py2app 打包为原生应用

### 🎨 界面设计
- 暗色毛玻璃风格设计
- 登录页毛玻璃效果
- 前端字段全部改为中文
- 响应式布局适配移动端
- 主题系统改为预设卡片选择器

### 🐛 修复
- 未登录访问 `/admin` 时自动跳转登录页（而非返回 JSON 错误）
- 适配新版 Starlette TemplateResponse API
- 今日访问/访问总量/月度对比只统计首页（home）
- 移除模板文件中残留的行号
- Banner 比例调整与文字溢出修复
- 主标题左侧留白优化

### 📦 架构
- 模块化代码结构：`main.py`（路由）、`database.py`（数据层）、`config.py`（配置）、`auth.py`（认证）
- SQLite WAL 模式提升并发性能
- 环境变量配置管理
- 代码审查报告（REVIEW.md）
